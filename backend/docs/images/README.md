# Figures committed in this folder

All figures below were made from the CT series `LIDC-IDRI-0709` (The Cancer Imaging Archive, CC BY 3.0, DOI 10.7937/K9/TCIA.2015.LO9QL9SX), which is not part of this repository. They are examples, not results: each shows one slice or one volume and one noise draw. Their titles contain the DICOM series UID.

| File | What it shows | How it was made | What was checked |
| --- | --- | --- | --- |
| `benchmark_gaussian_spatial.png`, `benchmark_salt_pepper_spatial.png`, `benchmark_speckle_spatial.png` | Slice 50 (zero-based, of 100): original, synthetic noise, 5 x 5 mean, median, Gaussian filter | `evaluate_denoising.py`, noise draw 1 of the historical benchmark. Gaussian: variance 0.02, seed 5000293; salt and pepper: amount 0.02, seed 5000403; speckle: variance 0.02, seed 5000499 (seed = `derive_run_seed(42, 50, noise, 0)`). Window -600/1500 HU. | Regenerated with the current code and the local series on 2026-10-26: **pixel-identical** (Matplotlib 3.11.2). They match the rows of `../results/denoising_benchmark.csv` for slice 50, repeat 1 (for example Gaussian noise: unfiltered 18.18 dB / SSIM 0.185, mean 24.90 / 0.612, median 27.67 / 0.618, Gaussian 25.22 / 0.543). |
| `ct_gaussian_spatial.png`, `ct_salt_pepper_spatial.png`, `ct_speckle_spatial.png`, `ct_salt_pepper_frequency.png` | The same slice and panels, from an earlier version of the script (commit `5f1093f`, 2026-10-10) | The same noise parameters but **seed 42 for every noise type**; the frequency panels use cutoff 0.10 | A regeneration with seed 42 reproduces them to within 1 to 2 gray levels, except in 0.006 to 0.04 % of the pixels of the median-filter panel (differences up to 211 levels; the cause, probably a change of the median implementation between versions, was not investigated). No recorded table belongs to this earlier run, so they are kept for traceability but are not used in the README. |
| `ct_volume_3d_grayscale.png`, `original_vs_smoothed_ct_3d_pseudocolor.png` | VTK volume renderings of the series; the second compares the series with a 1 mm Gaussian-smoothed copy | `run_3d_viewer.py` and `run_denoised_3d_viewer.py`, commands in `../results/3d_viewer_validation.md` | Not independently checked: whether the rendering geometry is right cannot be judged from the image; the mapping of spacing, origin and direction to VTK is covered by unit tests. A visual comparison says nothing about diagnostic quality. |

`original_vs_smoothed_ct_color.png`, a byte-identical copy of `original_vs_smoothed_ct_3d_pseudocolor.png` that nothing referenced, was removed; Git history keeps it.
