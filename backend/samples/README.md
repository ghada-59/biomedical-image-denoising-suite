# Bundled sample files

Three small files used by the 2D Denoising Lab and the tests. They are demonstration inputs, not data for any result reported in the main README (those use a CT series that is **not** part of this repository).

| File | What it is | Where it comes from | Terms | What was checked (2026-10-26) |
| --- | --- | --- | --- | --- |
| `head_ct.png` (256 x 256, 8 bit) | Slice 5 of the array returned by scikit-image's `data.brain()`, exported with `plt.imsave(cmap="gray")` by `download_data.py`. It shows a skull with bright bone and a head-rest, which makes it **most likely a head CT slice, not an MRI** (a judgement from the image; the PNG carries no metadata). | scikit-image sample data, itself a 10-slice subset of the University of North Carolina Volume Rendering Test Data Set (mirrored in the Stanford volume data archive, `https://graphics.stanford.edu/data/voldata/`). A secondary summary of that archive says it holds a CT cadaver head and an MR brain *with the skull removed*, which is why this slice (with skull) is taken to come from the CT head. scikit-image's own documentation does not state the modality. | **Not verified at the source.** A secondary summary says the archive is public domain with a request to credit the University of North Carolina; the archive page itself could not be opened. | The file is pixel-identical to a regeneration from scikit-image 0.26.0's cached `brain.tiff`, slice 5. The modality was judged from the image and the archive description, not from metadata (the PNG has none). |
| `cell_phase.png` (550 x 660, 8 bit) | A single cell floating in saline, a quantitative phase image from digital holography, with a banding artefact in the background. A microscopy image: not tissue and not radiological. | scikit-image's `data.cell()` (recorded with the Python library `qpformat`). | CC0 (public-domain dedication) according to the docstring of `data.cell()` in the installed scikit-image. | The docstring statement was read. Pixel equality with `data.cell()` was **not** tested (the file was not cached locally and was not downloaded). |
| `synthetic_ct_scan.dcm` (256 x 256) | A synthetic phantom: two concentric discs (about 40 HU and 400 HU) on -1000 HU with Gaussian noise of 15 HU (fixed seed), stored as a DICOM CT slice with RescaleSlope 1 and RescaleIntercept -1024. Not an anatomical image. | Generated by `download_data.py` in this repository. Patient name and ID are the fictional strings `Synthetic^Subject` and `SYNTH-0001`. | Generated for this project. | Regenerating with `download_data.py` gives identical pixel data and identical tags apart from the freshly generated UIDs. It has no pixel spacing or orientation, so the series loader cannot read it (it is meant for the 2D lab). |

The previous names of the first two files (`brain_mri.png`, `cells_tissue.png`) were inaccurate and were changed.

## Not in this repository

The CT series behind the benchmarks, `LIDC-IDRI-0709` (100 axial slices), comes from The Cancer Imaging Archive under CC BY 3.0 (DOI 10.7937/K9/TCIA.2015.LO9QL9SX) and stays local. Its identity with the public series was compared at the level of metadata (series and study UIDs, modality, manufacturer, model, software version, image count and the total size of the 100 files, all equal to TCIA's public record); file hashes were not compared with a fresh download. The runs record the SHA-256 of every file so anyone can compare their own copy.
